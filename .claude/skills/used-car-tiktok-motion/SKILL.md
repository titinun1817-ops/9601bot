# คลิป TikTok รถมือสอง · สงวนไทย (Sticker Pop จัดเต็ม + เสียงพากย์)

ตอบเป็นภาษาไทย น้ำเสียงเพื่อนคุยกัน งานนี้สรุปจากคลิป Spacecab 3.0 S ปี 2023 (v4 = เวอร์ชันที่ผู้ใช้ชอบ)

## 0. ลำดับงาน (ทำตามนี้)
1. **โหลดไฟล์จาก Drive:** ไม่มี connector ของ Drive ให้ใช้ `pip install gdown` แล้ว `gdown --folder <url>` เพื่อ **ดูรายชื่อไฟล์ + file id** อย่างเดียว ตัวดาวน์โหลดของ gdown โดน proxy บล็อก ให้โหลดเองด้วย
   `curl -sSL -o FILE "https://drive.usercontent.google.com/download?id=<ID>&export=download&confirm=t"` (ใช้ xargs -P 8 โหลดขนานกัน) เก็บไฟล์ในโฟลเดอร์ใหม่ของ scratchpad
2. **ทำ contact sheet** ของทุกคลิป (ffprobe + ภาพนิ่งกลางคลิป) แล้วเปิดดูเอง จัดหมวดว่าคลิปไหนเป็นช็อตอะไร: หน้าโชว์รูม/ป้ายสงวนไทย, รถวิ่ง, กระจัง, ไฟ, กระบะ, ท้าย, พวงมาลัย, จอ, เกียร์, เบาะ, หน้าปัดไมล์ ฯลฯ
   ฟุตเทจมือถือเป็นแนวตั้ง (rotation −90) ffmpeg หมุนให้อัตโนมัติ **ให้ทำคลิป 9:16 เสมอ**
3. **เช็กข้อมูลกับภาพจริง** เช่น ซูมดูเลขไมล์บนหน้าปัด ถ้าไม่ตรงกับการ์ดให้ถามผู้ใช้
4. **ถามสิ่งที่ต้องยืนยันด้วยปุ่มกด (AskUserQuestion)** ผู้ใช้ชอบแบบนี้ ไม่ชอบพิมพ์ตอบ
5. **สคริปต์ → เสียงพากย์** (ข้อ 3) → ถอดเสียงพร้อม timestamp รายคำ → วางไทม์ไลน์ภาพตามเวลาคำ
6. **ตัด bg frames** ด้วย `scripts/build_bg.py` ให้จำนวนเฟรมรวมตรงกับความยาวเสียงพอดี
7. **แก้เทมเพลต motion** (ข้อ 5) → เรนเดอร์ภาพนิ่ง 8–15 จุดด้วย `--stills` แล้วเปิดดูเอง → เรนเดอร์จริง
8. **มิกซ์เสียง** ด้วย `scripts/mix_audio.py` แล้ว mux + loudnorm −14 LUFS
9. **ตรวจก่อนส่ง** (ข้อ 7) แล้วส่งด้วย SendUserFile พร้อมตารางสรุปตามเวลาและสิ่งที่ต้องฟังเช็ก

## 1. ค่าเริ่มต้นที่ผู้ใช้ตั้งไว้ (อย่าถามซ้ำ)
- **ขนาด/ความยาว:** TikTok 1080×1920 · 30fps · ~30 วิ
- **ป้ายทะเบียน:** **ไม่เบลอ**
- **ดราฟต์แรก:** **ไม่ใส่ element จากไดรฟ์** (โลโก้ ป้ายประกัน ป้ายโปร) ใส่เมื่อผู้ใช้สั่งเท่านั้น วาดเองด้วย HTML/SVG แทน
- **ไม่ใส่โปรโมชัน** และ **ไม่ใส่เบอร์โทร** ถ้าไม่ได้สั่ง
- **เลขไมล์:** พูดเป็นช่วง เช่น "3 หมื่นกว่า กม." ไม่ต้องบอกเลขเป๊ะ
- **ฉากราคา:** **เน้นผ่อน/เดือน** เป็นตัวเลขหลัก ส่วนดาวน์กับราคาเต็มเป็นกล่องรอง
- **ปิดท้าย:** **มีแค่ปุ่ม "สนใจทักแชท"** วางกลางจอด้านล่าง (top ≈1170px)
- **ตำแหน่ง element:** ทุกชิ้นอยู่ **กลางจอด้านบน (center)**
- **เสียงพากย์:** **Anan** (`tAV9ucNkXgK2k9TLxWkM`, ชื่อ "Anan - Confident, Deep, Firm") โมเดล `eleven_v3`
- **ฟอนต์:** Kanit (โหลดด้วย `npm pack @fontsource/kanit` แล้วใช้ไฟล์ใน `package/files`) ใช้แทน DB Heavent จนกว่าผู้ใช้จะส่ง .TTF มา

  - "ที่เดียวกับอีซูซุป้ายแดง" ใช้เป็นเหตุผลให้ลูกค้าเชื่อใจได้

  - **10 ปีซ้อน** มีป้ายยืนยันในไดรฟ์ ("ผู้จำหน่ายยอดเยี่ยมอันดับ 1 · 10 ปีซ้อน")

  - คำว่าเทิร์น หรือสื่อว่ารับรถเก่า
  - "ดีที่สุด / ถูกที่สุด / ผ่านชัวร์ / อนุมัติง่าย / ไม่ต้องคนค้ำ"
  - เอาตัวเลขรถคันอื่นมาปน
- ประโยคแรงๆ ที่ผู้ใช้เขียนมาเอง (เช่น "ใครจะบ้าเอาชื่อมาเสี่ยง") ใช้ได้ แต่ให้แจ้งไว้หนึ่งบรรทัด
- **CTA:** "สนใจทักแชท"
- **สี:**
  - แดง #E3202A
  - หมึก #17181C
  - เขียว #5BB947 (ใช้กับเครื่องหมายถูกเท่านั้น)
  - ทอง #F5C518 / #FFE27A (ใช้กับรางวัลและคอนเฟตติ)

## 3. สคริปต์ + เสียงพากย์
**โครงสคริปต์ที่ผู้ใช้อนุมัติ** (ภาษาพูดคุยกับเพื่อน ไม่มี "ครับ" ยาว ~29 วิ):
| เวลา | เสียงพากย์ | บนจอ |
|---|---|---|
| 0–3 | ซื้อรถมือสองอะ… รู้ได้ไงว่าไม่โดนโกง? | บอลลูน "รู้ได้ไงว่าไม่โดน**โกง**" + "?" |
| 3–9 | โกงได้ไงล่ะ! ที่นี่อยู่ที่เดียวกับอีซูซุป้ายแดงเลยนะ รางวัลการันตีสิบปีซ้อน ใครจะบ้าเอาชื่อมาเสี่ยง | สแตมป์ "โกงได้ไง!" → ที่เดียวกับ / อีซูซุป้ายแดง / 🏆 10 ปีซ้อน |
| 9–14 | มาดูคันนี้ <รุ่น> <ปี> ไมล์เพิ่ง<ช่วง>เอง | SPACECAB · 3.0 · ปี 2023 · ไมล์ 3 หมื่นกว่า |
| 14–19 | ก่อนส่งมอบ เข้าศูนย์อีซูซุตรวจตั้ง 220 รายการ เครื่อง เกียร์ เฟืองท้าย ประกันให้อีกปีนึง | เช็กลิสต์ ✓ ตรวจ 220 ✓ รับประกัน 1 ปี/25,000 กม. |
| 19–26 | ผ่อนแค่เดือนละ <ผ่อน> เอง <งวด> งวด ดาวน์<ดาวน์> | ผ่อน/เดือน + 84 งวด / ดาวน์ · ราคา |
| 26–30 | สนใจก็ทักแชทมาเลย มีคันเดียว ช้าอดนะ! | ปุ่ม สนใจทักแชท |

**วิธีเจนเสียง:**
- **ตัวเลขเขียนเป็นคำอ่าน** ในพรอมป์ต์ เช่น "หกพันแปดร้อยเจ็ดสิบหก" "สองร้อยยี่สิบ" "สามจุดศูนย์" กันระบบอ่านผิด
- ใส่แท็กอารมณ์ได้ เช่น `[curious]` `[excited]` และเว้นบรรทัดว่างระหว่างประโยค
- เจน `generations_count: 1` **ครั้งเดียวทั้งสคริปต์** (ประมาณ 450 เครดิต) ห้ามเจนซ้ำเพื่อแก้จังหวะ ถ้าผู้ใช้จะแก้สคริปต์ ให้ยืนยันบทสุดท้ายก่อนแล้วค่อยเจน
- ใช้ flow เดิมได้ (ส่ง `flow_id` เดิม) แล้ว poll ด้วย `creative_get_flow_run_status` จนเสร็จ แล้วโหลดไฟล์จาก `content_url` ด้วย curl

**ถอดเสียงเช็ก:** ใช้ `mcp__Speko__audio_transcribe` (`language:"th"`, `word_timestamps:true`) กับ content_url
- เช็กว่าตัวเลขทุกตัวถูก
- ใช้ start_ms ของแต่ละคำวางจังหวะภาพ (คำสำคัญ → pop/slam, ตัวเลข → จุดลงตัว)
- ระบบถอดเสียงฟังผิดได้ (เช่น "การันตี" → "การตี", "ทักแชท" → "ทัชชัด") ให้แจ้งผู้ใช้ไปฟังเช็กตรงวินาทีนั้น

วางเสียงทั้งไฟล์ที่ offset 0.15 วิ (ง่ายสุด) หรือตัดทีละประโยคด้วย `vo_lines` ใน cues.json (เร่งได้ไม่เกิน 1.3 เท่า)

## 4. ไทม์ไลน์ภาพ (ตัวอย่าง Spacecab · 900 เฟรม)
`SEG=[0,2.85,10.0,14.95,21.5,25.8,30.05]` ฉาก: hook / แบรนด์ / ข้อมูลรถ / เช็กลิสต์ / ผ่อน / CTA

| ฉาก | ฟุตเทจ |
|---|---|
| hook | รถวิ่ง |
| แบรนด์ | หน้าโชว์รูมที่เห็นป้ายสงวนไทย 2 ช็อต ตัดตอนพากย์พูด "รางวัล" |
| ข้อมูลรถ | รถหน้าเสาป้าย ISUZU → หน้าปัดไมล์ ตัดตอนพากย์พูด "ไมล์" |
| เช็กลิสต์ | มอนทาจ 7 ช็อต ช็อตละ ~0.93 วิ (กระจัง ไฟหน้า พวงมาลัย จอ เกียร์ กระบะ ไฟท้าย) |
| ผ่อน | ภาพเด่นหน้ารถหน้าโชว์รูม |
| CTA | ท้ายรถมุมเฉียง |

`scripts/example_shots.json` คือ shot list จริงของงานนี้ ใส่ speed 1.12 ได้ถ้าคลิปสั้นกว่าที่ต้องการ

## 5. Motion (เทมเพลต `templates/sticker_pop_epic.html` + `templates/engine.html`)
แต่ละฉากเป็น `<div class=sc id=sN>` และ `render(t)` คุมทุกชิ้นเป็นฟังก์ชันของเวลา เวลาที่ต้องแก้อยู่ใน `SEG`, `CUTS`, `BIG`, `LAND`, `LOCK`, `FINAL`, `RING_AT`, `CF_AT`, `SPEED_AT` และตัวเลขเวลาที่ฝังในแต่ละฉาก (มาจากเวลาคำในข้อ 3) ข้อความกับตัวเลขรถแก้ใน DOM

**ภาษาภาพ (Sticker Pop):**
- สติกเกอร์ขอบขาว 9px + เส้นหมึก 6px + เงาแข็ง
- บอลลูนคำพูดมีหาง
- ฉากราคาใช้ตัวเลขใหญ่ขาว ขอบหมึก เงาแดง (`.numA`) กับป้ายแดงเอียง (`.tagA`)

**ชุดเอฟเฟกต์ "จัดเต็ม" ที่ผู้ใช้ชอบ:**
- `pop`: back-out ครั้งเดียว ห้ามหมุนเหวี่ยงหรือส่ายค้าง เพราะผู้ใช้บอกว่าดูแปลก
- `slam`: ย่อจาก 2.4–3.2 เท่า + เบลอ → 1 ใน 0.18 วิ ตามด้วยจอสั่น `shake` + แฟลช + คลื่นกระแทก `.ring`
- **Hook:**
  - ขอบจอมืด (vignette) ไต่ขึ้นเรื่อยๆ และพื้นหลังเต้นตุบเหมือนหัวใจ
  - คำกระแทกทีละคำตามเสียง ส่วน "?" หมุนเข้ามาแล้วเต้น
- **สแตมป์** "โกงได้ไง!" กรอบแดงเอียง กระแทกแล้วลอยหายตอนเสียงพากย์จบท่อน (เติมช่องว่างที่ไม่มีตัวหนังสือ)
- **รางวัล:** รัศมีทองหมุน ป้ายถ้วยนับ **1→10** พอลงตัวมีคอนเฟตติทองกับแสงวิ่ง (shine)
- **ข้อมูลรถ:**
  - เส้นสปีดพุ่ง
  - SPACECAB กระแทก "3.0" มีแสงวิ่ง
  - ไมล์เป็นตัวเลขหมุน **แบบเบลอ** แล้วล็อกที่ "3" (ต้องเบลอ เพราะเลขที่ผ่านระหว่างหมุนเป็นเลขผิด)
- **เช็กลิสต์:**
  - กรอบ HUD สี่มุมกับเส้นสแกนวิ่งไล่ลงบนภาพ
  - "ตรวจ 0→220" นับขึ้น แล้วติ๊กถูกพร้อมวงเขียว
  - บรรทัดรับประกันเผยด้วย clip-path แล้วติ๊กตามเสียงพากย์
- **ผ่อน (จังหวะใหญ่สุด):**
  - จอมืดลง + ซูมเข้าช้าๆ
  - ตัวเลขหมุนแบบสล็อต (เบลอ) แล้ว **ล็อกทีละหลักซ้ายไปขวา** หลักสุดท้ายลงตรงคำที่พากย์พูดเลขจบพอดี
  - ลงตัวแล้วมีแฟลช + คลื่นกระแทก 2 วง + คอนเฟตติแดงทอง + ประกาย + รัศมี + จอสั่นแรง
  - จากนั้น "บาท" ป๊อป ส่วน "84 งวด" กับกล่องดาวน์/ราคากระแทกตามคำพากย์
- **CTA:**
  - ปุ่มหล่นลงมาเด้ง (bounce) มีวงกระเพื่อม 2 วง และคอนเฟตติ
  - ตอนพากย์ "มีคันเดียว ช้าอดนะ" ปุ่มเต้นถี่ขึ้นและเรืองแสงแดง
- **เปลี่ยนฉากใหญ่:** zoom-whip คือพื้นหลังเบลอพุ่งถึง 16px + ขยาย 16% แล้วคลาย 0.3 วิ พร้อมแฟลช 35%
- **ตัดช็อตย่อย:** ซูม punch แค่ 4%
- **ก่อนออกจากฉาก:** element ลอยขึ้นแล้วหายไป (`outFly`)

**โซนปลอดภัย TikTok (ห้ามมีตัวหนังสือ):**
- บน 0–150px
- ล่าง 1440–1920px
- ขวา x>930 ช่วง y 620–1440

element บนจอใช้ `.row` (left:0; right:0; text-align:center) ให้อยู่กึ่งกลาง ส่วนกล่องที่กว้างให้แคบกว่า 760px

## 6. คำสั่ง
```bash
python3 scripts/build_bg.py shots.json CLIPDIR WORK/bg
python3 scripts/render.py --style templates/sticker_pop_epic.html --bg WORK/bg --fonts WORK/fonts --frames 900 --out WORK/v.mp4 --stills 2.6,3.2,7.8,13.4,17.3,22.8,23.9,26.3
python3 scripts/render.py --style templates/sticker_pop_epic.html --bg WORK/bg --fonts WORK/fonts --frames 900 --out WORK/v.mp4
python3 scripts/mix_audio.py cues.json WORK/vo.mp3 WORK/mix.wav
ffmpeg -i WORK/v.mp4 -i WORK/mix.wav -filter_complex "[1:a]loudnorm=I=-14:TP=-1.5[a]" -map 0:v -map "[a]" -c:v copy -c:a aac -b:a 192k -ar 48000 -shortest -movflags +faststart OUT.mp4
```
- Playwright: Chromium ติดตั้งไว้แล้วที่ `/opt/pw-browsers` ถ้ายังไม่มี Python Playwright ให้ `pip install playwright` อย่างเดียว ห้าม `playwright install`
- ทำ render กับ mix_audio ขนานกันได้ ใช้เวลาประมาณ 1.5 นาทีต่อ 900 เฟรม

## 7. ตรวจก่อนส่ง
- ffprobe ได้ 1080×1920, 30fps, ความยาวตรงกับที่วางไว้, มี aac, ความดัง −14 ±1 LUFS
- ดึงเฟรมจากไฟล์จริง 8 จุด (หนึ่งจุดต่อจังหวะเด่น) มาต่อเป็นแถบแล้วเปิดดู:
