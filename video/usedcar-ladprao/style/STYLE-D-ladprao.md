
### D. พรีเซนเตอร์ + โมชั่น 3 ชั้น "ลาดพร้าว" — ผู้ใช้อนุมัติ 2026-11-18 ("ช่วยจดจำสไตล์นี้ไว้ ฉันชอบ")
อ้างอิง: คลิปสงวนไทยรถมือสอง สาขาลาดพร้าว (ดราฟ 6) โปรเจกต์ HyperFrames `video/usedcar-ladprao` ใน repo titinun1817-ops/9601bot (branch claude/brave-pasteur-4hrcs4) มีสคริปต์เตรียมฟุตเทจใน `tools/`
ใช้เป็นค่าเริ่มต้นเมื่อผู้ใช้ให้คลิปพรีเซนเตอร์ยืนพูดหน้าโชว์รูม/สาขา แล้วขอ "ซับ + แอนิเมชันช่วยขยายความ"
- **สี:** ขาว 70% / แดง #E3202A 15% / เขียว #5BB947 15% · ฟอนต์ Kanit ตระกูลเดียว (Black/ExtraBold/Bold) จนกว่าจะได้ DB HelvethaicaMon
- **ซับ:** กลางล่าง (top≈1220 ใน 1080×1920) ไม่บังหน้า ทีละ 2–3 คำ เด้งเข้าทีละคำตรงเวลาพูด (back.out) ตัวขาวขอบดำหนา คำสำคัญอยู่ในกล่องแดง/เขียวขอบขาว · ถอดเสียงด้วย Whisper large-v3 (ภาษาไทย) แล้วแก้คำผิดเอง
- **3 ชั้นลึก (เอฟเฟกต์คน):** ฟุตเทจ → กราฟิก "หลังคน" → ตัวคนที่ตัดพื้นหลัง (u2net_human_seg ทุกเฟรม, WebM alpha) → กราฟิกหน้า → ซับ
  - โลโก้/ตัวหนังสือหลังคน ให้คน **ทับแค่นิดหน่อย** (หัวบังขอบล่าง) ไม่ใช่บังกลางคำ
  - ช่วงพีค: เลขยักษ์แดงขอบขาวอยู่หลังหัว + เส้นเรืองแสงขาวรอบตัวคน
- **กล้อง:** ครอปซูมจากไฟล์ 4K (ไม่แตก) จังหวะซูมเข้า-ออกตามคำสำคัญ: เปิดด้วยซูมออก, กระตุกซูมเข้า 0.2 วิ (expo) ตรงคำเด่น, ซูมออกเผยตึกตอนพูดถึงตึก, snap zoom 2× ช่วงพีค · ทรานสิชันปาดเฉียง ขาว-แดง-เขียว ตอนตัดช็อต
- **ช็อตเปิด:** โลโก้แดง-เขียว "สงวนไทย | รถมือ 2" + แถบขาว "รถสวย สภาพดี **เลขไมล์แท้**" ลอยเหนือหัว + "สาขา**[ชื่อสาขา]**" ตัวใหญ่ขอบดำ (ชื่อสาขาเขียว) คนทับเล็กน้อย
- **"บริษัทในเครือ":** การ์ดขาว + head-02.png (อีซูซุ สงวนไทย อันดับ 1) อยู่หลังหัว มีแสงวิ่งผ่าน
- **ช่วงพีค (เช่น "อันดับหนึ่ง 10 ปีซ้อน") ต้องอลังการ:** riser → แฟลช 1 ครั้ง + snap zoom + กล้องสั่น → เลข 1 ขึ้นหลังหัว → นับ 1→10 เร็วมีเสียงติ๊ก → เลขกระแทก elastic + แสงวาบ + วงคลื่นขาว/แดง + รัศมีหมุนแรง + คอนเฟตตีขาว/แดง/เขียว ทั้งหลังและหน้าคน (ไม่บังหน้า) โปรยต่อข้ามช็อต + ดาวประกาย + คำรอง ("ปีซ้อน") เด้ง elastic
- **บอกตำแหน่ง:** หมุด/ป้ายปักติดตึกแบบ track กล้อง (optical flow) — "ชั้น 2" หมุดเขียว, กรอบมุมล็อกป้าย ISUZU + ป้ายแดง "อีซูซุ สยามซิตี้", "ตึกเดียวกัน"
- **แผนที่ = 3D isometric** (ไม่ใช่แผนที่แบน): ฐานบล็อกขาวลอย, ถนนเทาเข้มเส้นประขาว + ป้ายชื่อถนนดำ, ตึกกล่องขาวงอกทีละหลัง, ต้นไม้เขียว, ตึกเป้าหมายแดงหลังคาเขียว, หมุดแดงหล่นเด้ง + วงคลื่น, ป้ายขาว "ปากซอย**ลาดพร้าว 21**" ใต้แผนที่ (ตัวสร้าง: `tools/isomap.py`)
- **ตอนจบ:** ไม่ทำการ์ดท้ายพื้นขาว / ไม่ใส่โลโก้มุมขวาบนตลอดคลิป → เอาโลโก้ LP-01 (สงวนไทย รถมือ 2 / บริษัทในเครือ) + การ์ดสาขาขึ้นบนภาพจริงตอนพรีเซนเตอร์กางแขน
  - การ์ดสาขา: การ์ดขาว หมุดแดงเด้ง + ชิปเขียว "สาขา" + ชื่อสาขาตัวใหญ่ + แถบแดงไอคอนโทรศัพท์วงกลมขาว เบอร์กลิ้งขึ้นทีละตัว ไอคอนสั่น แสงวิ่ง · ปุ่มแดง "สนใจทักแชท" เต้นเบาๆ
- **เสียง:** เสียงพูดจริง + ซาวด์เอฟเฟกต์ทุกจังหวะ (ผู้ใช้บอกว่าคลิปไม่มี SFX "ดูแห้ง"): วูบตอนซูม/ปาด, ป๊อปตอนป้ายขึ้น, ตุบตอนโลโก้/หมุดลง, ติ๊กตอนตัวเลขนับ, ตูม+ฉาบตอนพีค, กริ๊งตอนแสงวิ่ง · ถ้า ElevenLabs ใช้ไม่ได้ สังเคราะห์เอง (`tools/sfx.py`) · ลูดเนส ~-15 LUFS
- ความยาว ~13 วิ จบพร้อมภาพจริง ไม่ค้างเฟรม
