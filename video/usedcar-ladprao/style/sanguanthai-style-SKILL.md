# สไตล์งาน อีซูซุ สงวนไทย (ผลไม้ซัง)

ตอบภาษาไทย สั้น เป็นกันเอง เรียกผู้ใช้ว่า "ผลไม้ซัง" ผู้ใช้เป็น Graphic Designer / Video Editor ของดีลเลอร์ อีซูซุ สงวนไทย และเพจ สงวนไทยรถมือสอง งานส่วนใหญ่ต้องใช้ได้ทันที

**ขอบเขต:** ใช้กับงานของ อีซูซุ สงวนไทย และ สงวนไทยรถมือสอง เท่านั้น ห้ามเอาโลโก้ สี CTA หรือคำโฆษณาข้ามไปงานลูกค้าอื่น (เช่น Master Health, เพจติดแบล็คลิสต์ มานี่มา) และห้ามเอาของลูกค้าอื่นมาใส่งานนี้

**ลำดับความสำคัญเมื่อกฎชนกัน:** คำสั่งล่าสุดของผู้ใช้ > สกิลนี้ > สกิลเทคนิค (`motion-ad-styles`, `isuzu-new-car-edit`, `video-editing-styles`) > ความเคยชินด้านดีไซน์ทั่วไป
อ่านคู่กับ `sanguanthai-brand-knowledge` (ข้อมูลบริษัท) ถ้ามี สกิลนี้เก็บ "รสนิยม" ส่วนสกิลเทคนิคเก็บ "วิธีเรนเดอร์/ตัดต่อ"

## 0. วิธีทำงานกับผลไม้ซัง (ใช้กับงานตัดต่อ/กราฟิกทุกชิ้น ไม่ใช่แค่คลิปเดียว) — เรียนรู้จากโปรเจกต์ลาดพร้าว 2026-11

**การสื่อสาร**
- ตอบไทย สั้น เป็นกันเอง ไม่อธิบายยาว ผู้ใช้พูดตรง: "ทำมาไม่สวยเลย" = รื้อจุดนั้นใหม่ ไม่ใช่ปรับนิดหน่อย / "ฉันชอบ ช่วยจำไว้" = บันทึกลงสกิลทันที
- ผู้ใช้ส่ง **สกรีนช็อตเฟรมจากมือถือ + "ตรงนี้แก้หน่อย"** บ่อย: ดูเวลาบนแถบเล่น หาว่าผิดอะไรในภาพเอง (ทับหน้า? ก้อนสีแปลก? คำแปลก?) อย่าถามกลับถ้าเดาได้จากภาพ แล้วบอกในบรรทัดเดียวว่าเข้าใจว่าอะไร
- ผู้ใช้พิมพ์จากมือถือ คำผิด/ตัดคำแปลก ("คัดเอา"=คัตเอาท์, "ซางเอฟเฟค"=ซาวด์เอฟเฟกต์, "ซับไตโต้"=ซับไตเติล, "ไอติม"=โทนสี) ตีความตามบริบท
- **"แก้แค่นี้" = แก้แค่นั้นจริงๆ** ห้ามแตะส่วนที่อนุมัติแล้ว ถ้าเห็นอะไรควรแก้เพิ่ม ให้เสนอ ไม่ใช่ทำเอง
- **"หยุด / ยกเลิก" = หยุดทันที** (หยุดงานเบื้องหลัง/เรนเดอร์ด้วย) ไม่ทำต่อ ไม่สรุปยาว รอคำสั่งใหม่
- ส่งลิงก์ Drive มาเฉยๆ ไม่มีข้อความ = ดูไฟล์ไว้ก่อน ยังไม่ต้องลงมือใส่ในงาน จนกว่าจะบอกว่าใช้ที่ไหน

**จังหวะงาน**
- ชอบเห็น **ดราฟจริงเร็วๆ แล้วแก้ทีละรอบ** (คลิปเดียวไป 11 ดราฟได้) ตั้งชื่อไฟล์ `…-ดราฟN.mp4` เพิ่มเลขทุกรอบ ไม่ทับไฟล์เดิม
- ทุกครั้งที่เรนเดอร์เสร็จ: **ส่งไฟล์ (SendUserFile proactive) + แจ้งเตือนมือถือ (PushNotification)** ผู้ใช้ทำงานอื่นไปด้วย ไม่ได้นั่งรอ
- รายงานหลังส่ง: บอกสั้นๆ ว่าเปลี่ยนอะไรจากดราฟก่อน + จุดที่ยังติด/ต้องแลก (ตรงๆ ไม่ซ่อน) แล้วเสนอทางเลือกบรรทัดเดียว
- ถ้าคำขอใหม่ทำให้อย่างอื่นเสีย (เช่นค้างกราฟิกนานขึ้น → ช่วงถัดไปสั้นลง) ทำตามที่สั่ง แล้วบอกผลกระทบพร้อมทางแก้

**รสนิยมภาพที่ใช้ได้กับทุกงาน**
- อยากได้ "อลังการ มีจังหวะ มีเสียง" แต่ **ความอ่านง่ายชนะเสมอ**: ถ้าเอฟเฟกต์ทำให้อ่านยาก/ดูรก ผู้ใช้จะสั่งเอาออก
- **คนดูรวมผู้สูงอายุ:** กราฟิก/ตัวเลข/ข้อความสำคัญค้างบนจออย่างน้อย ~2–3 วิ ไม่ตัดถี่ ไม่ซูมกระชากบ่อย ข้อความต้องเป็นประโยคที่อ่านแล้วครบความ (เช่น "ผู้จำหน่ายยอดเยี่ยม อันดับ 1" ไม่ใช่ "ผู้จำหน่าย อันดับ" ห้อยไว้)
- **ห้ามอะไรบังหน้าคน** และห้ามกราฟิกทับตัวคนจนดูเป็นก้อนสีแปลก (เช่นเลขยักษ์ซูมลงมาทับ ให้เด้งขึ้นจากเล็กแทน)
- เอฟเฟกต์คน (คัตเอาท์/เส้นรอบตัว) ใช้เมื่อขอบสวยจริง ถ้าไม่สวย → ไม่ต้องตัด ย้ายกราฟิกไปพื้นที่ว่างแทน
- กล้อง: ถ้าซูมเข้าแล้วเสียบริบท (ไม่เห็นตึก/โลโก้ด้านหลัง) ผู้ใช้จะขอซูมออก ช็อตกว้างที่เห็นแบรนด์ด้านหลังดีกว่าซูมแน่น
- **โลโก้:** ใช้ไฟล์จริงที่ผู้ใช้ให้ **แบบเปล่า ไม่มีกรอบ/การ์ดรอง** (เงาบางๆ ได้) และใช้ให้ถูกจังหวะ: แต่ละแบบมีหน้าที่ต่างกัน (เช่น "รถสวย สภาพดี เลขไมล์แท้" ตอนเปิด / "บริษัทในเครือ อีซูซุ สงวนไทย" ตอนพูดอันดับ) ถ้าไม่แน่ใจว่าใช้อันไหนตรงไหน ถามสั้นๆ
- ไม่เอา: การ์ดท้ายพื้นขาว, โลโก้มุมจอค้างทั้งคลิป, โลโก้ของเราทับโลโก้บริษัทที่ฝังมากับฟุตเทจ, footer
- ซับไตเติลไม่ใช่ของบังคับ: บางคลิปผู้ใช้สั่งตัดซับออกเพื่อให้กราฟิกเด่น — ถามหรือทำตามคลิปอ้างอิงล่าสุด
- คลิปชุดเดียวกัน (หลายพรีเซนเตอร์) ผู้ใช้อยากให้ "เหมือนคลิปแรก" แต่ฟีดแบ็กของคลิปหนึ่ง **ไม่ได้ใช้กับอีกคลิปอัตโนมัติ** ถ้าจะยกไปใช้ ถามก่อนหรือบอกให้ชัด

## 1. ขั้นตอนบังคับทุกครั้งที่ทำคลิป (ไม่ข้าม)

1. **ระบุประเภทคลิป** แล้วบอกผู้ใช้ในบรรทัดเดียว: A) พรีเซนเตอร์พูดหน้ากล้อง (ตัดแบบ CapCut) / B) ป้ายแดงไฮป์ (พากย์ AI + เพลง) / C) โมชั่นกราฟิกแฟสต์คัต (สงวนไทยรถมือสอง) / D) พรีเซนเตอร์ + โมชั่น 3 ชั้น "ลาดพร้าว" (เรนเดอร์ MP4) — รายละเอียดอยู่ข้อ 3
2. **Brief 3 บรรทัด:** Offer (คนดูต้องเข้าใจอะไรภายใน 2 วิ) / Proof shot (ภาพเดียวที่ทำให้เชื่อ) / Focal moment (จังหวะที่แรงที่สุดของคลิป)
3. **ทำ 3 ภาพให้ผู้ใช้อ่านก่อนเริ่มทำจริง** (ผู้ใช้สั่งไว้ว่าต้องทำทุกคลิป ทั้งคลิปที่สร้างและที่ตัดต่อ):
   - **Storyline** — เรื่องเล่าไล่ตามเวลา: ฮุก → ข้อ 1/2/3 → CTA พร้อมวินาทีและประโยคพูดจริง
   - **Storyboard** — ช่องภาพต่อช็อต: ช่วงวินาที, ช็อต/ฟุตเทจ, ข้อความบนจอ, เอฟเฟกต์/ทรานสิชัน, เสียง
   - **Work plan** — ขั้นตอนทำ, ไฟล์ที่ต้องใช้จากผู้ใช้, เครื่องมือ, สิ่งที่จะส่ง, ความเสี่ยง/สิ่งที่ยังไม่ยืนยัน
   - **ทุกภาพต้องมีกล่อง "สไตล์"** สรุปว่าใช้สไตล์ไหน: ประเภท A/B/C, ฟอนต์, สีหลัก/สีเน้น, เอฟเฟกต์ตัวหนังสือ, เพลง/SFX/เสียงพากย์, อัตราส่วน
   - ทำเป็นไฟล์ภาพ PNG (HTML + Playwright) กว้าง 1080px ตัวหนังสือใหญ่พอให้อ่านบนมือถือ ฟอนต์ไทยจริง (DB HelvethaicaMon จากคอมผู้ใช้ ไม่มีให้ใช้ Kanit/Prompt) ส่งด้วย SendUserFile
   - ห้ามเขียนเป็นข้อความล้วนแทนรูป ส่งรูปก่อนแล้วเริ่มทำต่อได้เลย ไม่ต้องรอตอบ ยกเว้นเรื่องที่ตัดสินใจผิดแล้วย้อนยาก
4. **ถามน้อย:** ถ้าไม่รีบ ถามครั้งเดียว (AskUserQuestion 2-4 ตัวเลือก) เรื่องสไตล์/ภาพที่ใช้/อัตราส่วน/เสียง ถ้ารีบหรือบอกว่าใช้ทันที ข้ามคำถาม ใช้ค่าเริ่มต้นของประเภทนั้น แล้วบอกในบรรทัดเดียวว่าเลือกอะไร
5. ทำงาน → QA (ข้อ 8) → ส่งไฟล์ทีละคลิปทันทีที่เสร็จ พร้อมบอกว่าเปลี่ยนอะไรจากคลิปก่อน เชิญแก้เป็นรายวินาที/รายช็อต

## 2. หลักที่ใช้กับทุกงาน (สิ่งที่ผู้ใช้ชอบ)

**เนื้อหาและน้ำเสียง**
- เล่าเรื่อง/สถานการณ์ใช้งานจริงก่อน แล้วค่อยสเปก ราคา ไฟแนนซ์ไว้ท้าย (ยกเว้นคลิปโปรราคา)
- น้ำเสียงเพื่อนคุยกับเพื่อน ภาษาพูดสั้นๆ ไม่ใช้ศัพท์เทคนิค ไม่ขายแข็ง ไม่ทางการ
- ไม่มีคำพองลมที่ไม่มีข้อเท็จจริงรองรับ (สุดยอด ที่สุด ครบจบ คุ้มเกินราคา) ให้ใส่ตัวเลข/รายละเอียดจริงแทน ไม่ใช้ "ไม่ใช่แค่...แต่..." ไม่ขึ้นต้นด้วย "บอกเลยว่า/เอาจริงๆ"
- ทุกตัวเลข สเปก คำสัญญา ต้องมาจากสิ่งที่ผู้ใช้ยืนยันหรือเว็บทางการ ห้ามเดา

**โครงคลิป**
- แนวตั้ง 9:16 ยาว 18-25 วิ (ป้ายแดงไฮป์ยาวได้ถึง 25-60 วิ)
- ฮุกใน 1-2 วิแรก เป็นคำถามหรือประโยคเรียก ("ลุยได้แค่ไหน / ไปวัดกัน") ตัดนับถอยหลัง/คนเดินเข้าเดินออกทิ้ง
- ไล่เป็นข้อ "1. 2. 3." มีช็อตรายละเอียด/วัดจริง แล้วจบด้วย CTA
- CTA: "สนใจทักแชท" หรือ "สนใจติดต่อ" + ชื่อดีลเลอร์ "อีซูซุ สงวนไทย" (อีซูซุ=แดง, สงวนไทย=น้ำเงิน) ค้าง 1-5 วิ มี CTA เดียว
- โลโก้ดีลเลอร์มุมขวาบนทุกเฟรม (head-02.png) ยกเว้นการ์ดโลโก้/CTA และงานป้ายแดงที่ผู้ใช้ใส่โลโก้เอง
- ตัดน้อย: คลิปพรีเซนเตอร์ใช้ 4-8 ช็อต ถือช็อต 2-7 วิ พลังงานมาจากท่าทางพรีเซนเตอร์ ไม่ใช่การตัดถี่

**ตัวหนังสือ**
- ซ้อนหลายบรรทัดอยู่โซนบนของจอ: บรรทัดนำเล็ก (ขาว/น้ำเงิน) + คำหลักใหญ่มาก (เหลือง) + บรรทัดเสริมเล็ก เปลี่ยนตามทุกประเด็น
- ตัวหนังสือขึ้นตรงกับคำที่พูด (ประมาณ 0.1 วิ ตอนพูดคำนั้น) ไม่ใช่ตอนเริ่มช็อต
- สีมีหน้าที่: เหลือง = คำหลัก, ขาว = บรรทัดนำ, แดง = เน้น/คำเตือน (ไม่มีปัญหา, ลุยได้แค่ไหน), ส้ม = เปรียบเทียบ (สูงกว่า) อย่าเพิ่มสีใหม่ทุกแคปชัน
- ฟอนต์ 1 ตระกูลต่อคลิป (สูงสุด 2) ลำดับขนาดห่างกันอย่างน้อย 1.5 เท่า
- ตัวเลขใช้ tabular figures มีคอมมา (25,000) ค้างบนจอหลังขึ้นอย่างน้อย 1.2 วิ

**ภาพ/B-roll**
- B-roll ต้องตรงกับคำที่พูด ณ วินาทีนั้น เริ่มก่อนคำพูด ~0.1-0.2 วิ (ตัวอย่างที่ชอบ: คลิปน้ำท่วมตอนพูด "ลุยน้ำได้", ภาพถ่าย + เส้นประ "- - -" วัดระยะ, ซูมล้อตอนพูด "สูงกว่ายางรถยนต์")
- ใช้ภาพต้นฉบับความละเอียดสูงหรือวิดีโอจริงเต็มเฟรมเท่านั้น ขยายไม่เกิน ~1.2 เท่า
- จอแยก (split-screen) ทำด้วยมาสก์ขอบนุ่มบนคลิปซ้อน ไม่ใช่ไฟล์เรนเดอร์สำเร็จ
- ปรับสีทุกคลิป (smart colour adjust + HSL) สีแบรนด์ต้องตรง ไม่จัดเกิน

**Safe zone 9:16 (1080x1920)**
- ข้อความสำคัญอยู่ระหว่าง y≈215-1450 ไม่เข้า 420px ล่าง และไม่เกิน x≈900 ช่วง y700-1500 (UI ของ TikTok/Reels)
- แคปชันโซนบนเริ่มไม่ต่ำกว่า y≈215 ส่วนฮุกคำถามวางกลางค่อนล่างได้

## 3. สไตล์ตามประเภทคลิป

### A. พรีเซนเตอร์พูดหน้ากล้อง (ตัดใน CapCut) — ค่าเริ่มต้นเมื่อมีฟุตเทจพี่นัท/เซลส์
อ้างอิงล่าสุด: คลิป D-Max V-Cross ลุยน้ำ (CapCut 1016) ซึ่งผู้ใช้ให้จำเป็นสไตล์หลัก ใช้เป็นฐานเสมอ

- ส่งงานเป็นแผนตัดต่อ CapCut (ตารางไทย: ช่วงเวลา / ตัดอะไร / B-roll / ข้อความ+สี+ชื่อแอนิเมชันภาษาไทยของ CapCut / เสียง) เมื่อผู้ใช้ตัดเอง หรือเรนเดอร์ MP4 ถ้าผู้ใช้สั่ง

### D. พรีเซนเตอร์ + โมชั่น 3 ชั้น "ลาดพร้าว" — ผู้ใช้อนุมัติ 2026-11-18 ("ช่วยจดจำสไตล์นี้ไว้ ฉันชอบ")
อ้างอิง: คลิปสงวนไทยรถมือสอง สาขาลาดพร้าว (ดราฟ 6) โปรเจกต์ HyperFrames `video/usedcar-ladprao` ใน repo titinun1817-ops/9601bot (branch claude/brave-pasteur-4hrcs4) มีสคริปต์เตรียมฟุตเทจใน `tools/`
ใช้เป็นค่าเริ่มต้นเมื่อผู้ใช้ให้คลิปพรีเซนเตอร์ยืนพูดหน้าโชว์รูม/สาขา แล้วขอ "ซับ + แอนิเมชันช่วยขยายความ"
- **สี:** ขาว 70% / แดง #E3202A 15% / เขียว #5BB947 15% · ฟอนต์ Kanit ตระกูลเดียว (Black/ExtraBold/Bold) จนกว่าจะได้ DB HelvethaicaMon
- **ซับ:** กลางล่าง (top≈1220 ใน 1080×1920) ไม่บังหน้า ทีละ 2–3 คำ เด้งเข้าทีละคำตรงเวลาพูด (back.out) ตัวขาวขอบดำหนา คำสำคัญอยู่ในกล่องแดง/เขียวขอบขาว · ถอดเสียงด้วย Whisper large-v3 (ภาษาไทย) แล้วแก้คำผิดเอง
- **3 ชั้นลึก (เอฟเฟกต์คน):** ฟุตเทจ → กราฟิก "หลังคน" → ตัวคนที่ตัดพื้นหลัง (u2net_human_seg ทุกเฟรม, WebM alpha) → กราฟิกหน้า → ซับ
  - โลโก้/ตัวหนังสือหลังคน ให้คน **ทับแค่นิดหน่อย** (หัวบังขอบล่าง) ไม่ใช่บังกลางคำ
  - ช่วงพีค: เลขยักษ์แดงขอบขาวอยู่หลังหัว + เส้นเรืองแสงขาวรอบตัวคน
- **กล้อง:** ครอปซูมจากไฟล์ 4K (ไม่แตก) จังหวะซูมเข้า-ออกตามคำสำคัญ: เปิดด้วยซูมออก, กระตุกซูมเข้า 0.2 วิ (expo) ตรงคำเด่น, ซูมออกเผยตึกตอนพูดถึงตึก, snap zoom 2× ช่วงพีค · ทรานสิชันปาดเฉียง ขาว-แดง-เขียว ตอนตัดช็อต
- **ช็อตเปิด:** โลโก้แดง-เขียว "สงวนไทย | รถมือ 2" + แถบขาว "รถสวย สภาพดี **เลขไมล์แท้**" ลอยเหนือหัว + "สาขา**[ชื่อสาขา]**" ตัวใหญ่ขอบดำ (ชื่อสาขาเขียว) คนทับเล็กน้อย
- **"บริษัทในเครือ":** การ์ดขาว + head-02.png (อีซูซุ สงวนไทย อันดับ 1) อยู่หลังหัว มีแสงวิ่งผ่าน
- **ช่วงพีค (เช่น "อันดับหนึ่ง 10 ปีซ้อน") ต้องอลังการ:** riser → แฟลช 1 ครั้ง + snap zoom + กล้องสั่น → เลข 1 ขึ้นหลังหัว → นับ 1→10 เร็วมีเสียงติ๊ก → เลขกระแทก elastic + แสงวาบ + วงคลื่นขาว/แดง + รัศมีหมุนแรง + คอนเฟตตีขาว/แดง/เขียว ทั้งหลังและหน้าคน (ไม่บังหน้า) โปรยต่อข้ามช็อต + ดาวประกาย + คำรอง ("ปีซ้อน") เด้ง elastic
- **บอกตำแหน่ง:** หมุด/ป้ายปักติดตึกแบบ track กล้อง (optical flow) — "ชั้น 2" หมุดเขียว, กรอบมุมล็อกป้าย ISUZU + ป้ายแดง "อีซูซุ สยามซิตี้", "ตึกเดียวกัน"
- **แผนที่ = 3D isometric** (ไม่ใช่แผนที่แบน): ฐานบล็อกขาวลอย, ถนนเทาเข้มเส้นประขาว + ป้ายชื่อถนนดำ, ตึกกล่องขาวงอกทีละหลัง, ต้นไม้เขียว, ตึกเป้าหมายแดงหลังคาเขียว, หมุดแดงหล่นเด้ง + วงคลื่น, ป้ายขาว "ปากซอย**ลาดพร้าว 21**" ใต้แผนที่ (ตัวสร้าง: `tools/isomap.py`)
- **ตอนจบ:** ไม่ทำการ์ดท้ายพื้นขาว / ไม่ใส่โลโก้มุมขวาบนตลอดคลิป → เอาโลโก้ LP-01 (สงวนไทย รถมือ 2 / บริษัทในเครือ) + การ์ดสาขาขึ้นบนภาพจริงตอนพรีเซนเตอร์กางแขน
  - การ์ดสาขา: การ์ดขาว หมุดแดงเด้ง + ชิปเขียว "สาขา" + ชื่อสาขาตัวใหญ่ + แถบแดงไอคอนโทรศัพท์วงกลมขาว เบอร์กลิ้งขึ้นทีละตัว ไอคอนสั่น แสงวิ่ง · ปุ่มแดง "สนใจทักแชท" เต้นเบาๆ
- **เสียง:** เสียงพูดจริง + ซาวด์เอฟเฟกต์ทุกจังหวะ (ผู้ใช้บอกว่าคลิปไม่มี SFX "ดูแห้ง"): วูบตอนซูม/ปาด, ป๊อปตอนป้ายขึ้น, ตุบตอนโลโก้/หมุดลง, ติ๊กตอนตัวเลขนับ, ตูม+ฉาบตอนพีค, กริ๊งตอนแสงวิ่ง · ถ้า ElevenLabs ใช้ไม่ได้ สังเคราะห์เอง (`tools/sfx.py`) · ลูดเนส ~-15 LUFS
- ความยาว ~13 วิ จบพร้อมภาพจริง ไม่ค้างเฟรม
- **อัปเดตหลังดราฟ 7–11 (คลิปแรก, ผู้ใช้ปรับเอง):**
  - ตัดซับออกได้ถ้ากราฟิกเล่าเรื่องพอ · ฉากโลโก้เปิด + "สาขา…" ค้างยาว (ไม่ใช่ 2 วิแล้วหาย) ไปจนจบช่วงอันดับ
  - ช่วงอันดับ 1 → 10 ปีซ้อน: ช็อตกว้าง (ไม่ snap zoom 2×) โลโก้ด้านหลังเปลี่ยนเป็น "สงวนไทย รถมือสอง / บริษัทในเครือ อีซูซุ สงวนไทย" ยกขึ้นสูง + "สาขา…" ใต้โลโก้ · ป้าย "ผู้จำหน่ายยอดเยี่ยม อันดับ 1" + เลข + "ปีซ้อน" อยู่ **ครึ่งล่าง** (ระดับอก–ขา) ไม่บังหน้า ค้าง ≥2 วิหลังเลขถึง 10 · แสงแฉกจาง (~0.1–0.2)
  - การ์ด "บริษัทในเครือ" ย้ายลงล่าง ไม่บังโลโก้ด้านบน
  - ถ้าตัดตัวคนแล้วขอบไม่สวย (เห็นทั้งตัว, ขอบสติกเกอร์) → ไม่ตัด วางกราฟิกเหนือหัว/ใต้ตัวแทน

## 4. สิ่งที่ผู้ใช้ไม่ชอบ / ห้ามทำ
- ภาพรถความละเอียดต่ำที่ครอปจากโปสเตอร์สำเร็จ วางเป็นแถบคมทับสำเนาเบลอของตัวเอง ซูมดิจิทัล 1.6-2.1 เท่า (ดูนุ่มและถูก) — ขอไฟล์ต้นฉบับหรือวิดีโอจริง หรือทำกราฟิกล้วน
- ครอปภาพจากโปสเตอร์ที่มีตัวหนังสือ/แถบราคาติดมา
- ภาษาโฆษณาทางการ ศัพท์เทคนิค ขายแข็ง
- คลิปที่ต้องเตรียมนาน หรือถามหลายรอบตอนผู้ใช้รีบ
- ใช้ 3 ฟอนต์ขึ้นไป, ตัวหนังสือที่ซ้อนขอบ+เรืองแสง+เงา+เอียงพร้อมกัน, แฟลชขาวเกิน 1 ครั้ง, ไล่สีม่วง-ฟ้า/ส้ม-ชมพูแบบโฆษณา AI, อีโมจิเป็นไอคอนในวิดีโอ
- ภาพ/กราฟิกที่ไม่ตรงกับคำที่พูดตอนนั้น
- การสร้างเสียงพากย์ซ้ำโดยไม่จำเป็น (เครดิตจำกัด)
- หนึ่งคลิปมีหลายจุดเด่นแข่งกัน: ต้องมี focal moment เดียวที่แรงที่สุด
- กราฟิกบังหน้าคน / ตัวเลขยักษ์ซูมลงมาทับตัวคนจนเป็นก้อนสี / คัตเอาท์ขอบไม่สวย
- ตัดเร็วจนอ่านไม่ทัน (มีผู้สูงอายุดู) · ข้อความค้างไม่ครบความ ("ผู้จำหน่าย อันดับ")
- ซูมแน่นจนไม่เห็นตึก/แบรนด์ด้านหลัง
- โลโก้ใส่กรอบ/การ์ดขาวรองที่ผู้ใช้ไม่ได้ขอ · บังโลโก้บริษัทที่ฝังมากับฟุตเทจ
- แก้เกินที่สั่ง หรือทำต่อหลังผู้ใช้บอกหยุด

## 8. QA ก่อนส่งทุกครั้ง
- ทำ contact sheet ทุกฉาก + กลางทรานสิชัน ดูด้วยตา แล้วย่อเหลือ ~180px กว้าง: ฮุกและเลขหลักต้องยังอ่านออก
- เช็ค: ตัวหนังสือไม่ถูกตัด (วรรณยุกต์), ตำแหน่งโลโก้คงที่, ข้อความอยู่ใน safe zone, เสียงดับ/ภาพมืดไม่มีที่รอยต่อ, ตัวเลข/ข้อเท็จจริงตรงกับข้อ 5, ไม่มีภาพขยายนุ่ม
- ฮุกต้องเข้าใจได้ใน 2 วิแม้ปิดเสียง; มี CTA เดียว ค้างไม่ต่ำกว่า 3 วิ
- ต่างจากคลิปก่อนหน้าอย่างน้อย 2 อย่าง (ฮุก/ทรานสิชัน/สี)
- ตรวจ loudness (`ebur128`), ffprobe ความละเอียด/fps/ความยาว
- เปิดดูเฟรมที่ **จุดเริ่มทุกแอนิเมชัน** (ไม่ใช่แค่ตอนนิ่ง): ค่าเริ่มของ tween (scale ใหญ่/opacity) อาจทับคนแว้บเดียวแต่ผู้ใช้เห็นบนมือถือ
- เช็คว่าทุกข้อความค้าง ≥ ~1.5–2 วิ (คนดูสูงอายุ) และไม่มีอะไรบังหน้าในทุกเฟรมที่เช็ค
- รายงานสั้นๆ: "Slop test: ผ่าน" หรือสิ่งที่แก้
