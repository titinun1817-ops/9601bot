# ส่งต่องาน: คลิปสงวนไทยรถมือสอง สาขาลาดพร้าว

## ผู้ใช้
- "ผลไม้ซัง": กราฟิกดีไซเนอร์และคนตัดต่อของ อีซูซุ สงวนไทย / สงวนไทยรถมือสอง
- คุยภาษาไทย สั้นๆ เป็นกันเอง
- เรนเดอร์เสร็จแล้ว **ส่งไฟล์ (SendUserFile, proactive) + แจ้งเตือนมือถือ (PushNotification) ทุกครั้ง**
- คลิปนี้มี **ผู้สูงอายุดูด้วย** → กราฟิกต้องค้างนานพอให้อ่านทัน ไม่ตัดเร็ว
- ถ้าผู้ใช้บอก "แก้แค่นี้" ให้แก้เฉพาะจุดนั้นจริงๆ ห้ามแตะส่วนอื่น
- ห้ามแต่งข้อมูลแบรนด์เอง
  - ใช้เบอร์สาขาลาดพร้าว **086-772-3333** (มาจาก asset LP-01 ปี 2025)
  - "อันดับหนึ่ง 10 ปีซ้อน" ใช้ได้เพราะพรีเซนเตอร์พูดเอง

## สไตล์ (สไตล์ D ที่ผู้ใช้อนุมัติ + ฟีดแบ็กล่าสุด)
รายละเอียดเต็มอยู่ที่ `video/usedcar-ladprao/style/STYLE-D-ladprao.md` สรุปที่ต้องจำ:
- **สี:** ขาว 70% / แดง #E3202A 15% / เขียว #5BB947 15%
- **ฟอนต์:** Kanit (Black/ExtraBold/Bold/SemiBold) อยู่ใน `assets/fonts`
- **ชั้นภาพ (z-index):**
  1. camA (ฟุตเทจ)
  2. behind (กราฟิกหลังคน)
  3. camB (ตัวคนตัดพื้นหลัง cut.webm)
  4. front (กราฟิกหน้าคน)
  5. captions
- **เอฟเฟกต์หลังคน:** โลโก้/ตัวหนังสือหลังคน ให้คนทับแค่นิดหน่อย
- **โลโก้:** ใช้ไฟล์ที่ผู้ใช้ให้ **แบบเปล่าๆ ไม่มีกรอบ** ใส่เงาบางๆ
- **ไม่ใส่:** การ์ดท้ายพื้นขาว, โลโก้มุมขวาบน, โลโก้ของเราเองด้านล่าง
- **เสียงประกอบ:** ต้องมีทุกจังหวะ ไม่งั้น "ดูแห้ง" สังเคราะห์ด้วย `tools/sfx.py` ปรับ loudnorm ที่ -15 LUFS
- **แผนที่ "ปากซอย":** ต้องเป็น 3D isometric (`tools/isomap.py`)
- **ตัดตัวคน (คัตเอาท์):** ถ้าทำแล้วไม่สวย ไม่ต้องทำ ให้ย้ายกราฟิกไปไว้จุดที่ไม่บังหน้าแทน
- **ช่วงพีค:** อย่าเอาตัวเลขใหญ่ซูมลงมาทับตัวคน (เกิดเป็นก้อนแดงทับ) ให้เด้งขึ้นจากเล็กแทน

## ขั้นตอนเตรียมฟุตเทจ (คลิป 4K)
อธิบายไว้ใน `tools/README.md` ของแต่ละโปรเจกต์
1. `tools/camera.json` เก็บคีย์กล้องเป็น `[t0,t1,zoom0,zoom1,cy0,cy1,ease]`
   - ease `'s'` = smoothstep, `'o'` = expo-out
   - cy คือสัดส่วนแนวตั้งของจุดกลางเฟรม ค่าน้อยลง = คนลงต่ำในเฟรม
2. รัน `bake2.py camera.json <source.mov> cam.mp4` เพื่อครอปจาก 4K ด้วย OpenCV
   - คลิป 1 ตัด 0.7 วิแรก ยาว 13 วิ
   - แล้ว mux เสียงจากฟุตเทจเดิมเป็น `assets/footage.mp4`
3. แตกเฟรม → `seg.py u2net_human_seg frames masks <from> <to>` (rembg)
   - คลิป 2/3 ต่อด้วย `headclip2.py` (MediaPipe face, โมเดล `face.tflite`) เพื่อตัดโปสเตอร์ที่ติดหัวออก
4. `cut.py` → `cut/` + `ring/` → VP9 alpha:
   ```
   ffmpeg -framerate 30 -i cut/%04d.png -c:v libvpx-vp9 -pix_fmt yuva420p -b:v 0 -crf 22 -deadline good -cpu-used 4 -row-mt 1 -auto-alt-ref 0 cut.webm
   ```
5. ป้ายติดตึก (ชั้น 2 / อีซูซุ สยามซิตี้): `track.py` (LK optical flow) → `const TRACK=[...]` ใน `front.html`
   - index = `Math.round(tp.t*30) - OFFSET`
   - ถ้าเปลี่ยนกล้องในช่วงที่ track อยู่ ต้องทำ track ใหม่
6. คลิป 3 ใช้ `tools/retime.py` + `anchors.json` แมปเวลาจากคลิป 1 ไปตามเสียงพูดของคลิป 3
- **Whisper:** faster-whisper large-v3 ต้องตั้ง `HF_HUB_DISABLE_XET=1` และ `SSL_CERT_FILE=/root/.ccr/ca-bundle.crt`
- **ข้อห้ามของ HyperFrames:**
  - ห้ามใส่ transform ที่ `.clip`
  - host ของ sub-composition ต้องเป็นลูกตรงของ root (ห้ามห่อด้วย div)
  - ใช้ fromTo + immediateRender ระวังค่าเริ่มต้นโผล่ก่อนเวลา: ให้ตั้ง `data-start` ของกลุ่มให้ตรงกับเวลาที่ควรเห็น

### คลิป 1: พี่ผู้หญิงคนแรก, ดราฟ 11 (ส่งแล้ว รอฟีดแบ็ก)
- ไม่มีซับไตเติล (ผู้ใช้สั่งเอาออก, ถอด host captions ใน `index.html`)
- **0.2–4.7 วิ:** โลโก้ official + "สาขาลาดพร้าว" อยู่หลังคน
  - กล้องกว้างค่อยๆ ดันเบาๆ (1.18→1.27) ไม่มีปาดตัดช็อตกลาง
  - 2.6–4.5 วิ: การ์ด "บริษัทในเครือ" (`head-02`) อยู่ด้านล่าง layer front
- **4.7–8.3 วิ:**
  - สลับเป็น `logo-usedcar-group.png` ขยับขึ้น (top 420) และ "สาขาลาดพร้าว" เลื่อนขึ้นมาอยู่ใต้โลโก้ (y −110)
  - กล้องถอยออกกว้าง (1.27→1.0)
  - ป้าย "ผู้จำหน่ายยอดเยี่ยม **อันดับ 1**" (top 1075) → เลข 1 เด้งขึ้น → นับ 1→10 → "ปีซ้อน" + แถบแดง
    - ทั้งชุดอยู่ด้านล่าง layer front (ย้ายมาจาก behind) ค้างถึง 8.3 วิ
    - แสงแฉกจางลง (opacity 0.12/0.22)
- **8.3 วิ:** ปาดเฉียง → ป้าย "ชั้น 2" / "อีซูซุ สยามซิตี้" / "ตึกเดียวกัน" ขึ้นที่ 8.42–8.85 วิ ออก 9.55 วิ

- **10.9–13 วิ:** โลโก้ LP-01 + การ์ดสาขา/เบอร์ + ปุ่ม "สนใจทักแชท"
- **ค้างอยู่:**
  - ป้ายชั้น 2 / สยามซิตี้ ขึ้นช้ากว่าเสียงพูดและค้างแค่ประมาณ 0.7 วิ
